## ♻️ Reset, Verify, Then Never Reset Again

The reset is a one-time operation per machine. Doing it repeatedly is a pattern in
itself and gains nothing.

**The full sequence, once**

1. Close the game **and** its launcher — check the tray.
2. Run the loader as administrator.
3. Record the current identifiers.
4. Apply the reset.
5. Reboot.
6. Re-read the identifiers and compare.
7. Only if every value moved: create the new account.

**Why once is enough**

The identifiers do not drift back. Once the volume serial and board UUID are
replaced, they stay replaced until something else changes them. Re-running the
reset on an already-clean machine produces new values for no benefit and adds
churn that a clean machine would not have.

**What to do if a later account is banned**

That is an account-side event, not a hardware one. Resetting again will not help.
The correct response is a new account, not another reset.

**Keeping the record**

Store the before/after values with the config. If you ever need to explain the
machine's history to yourself, that record is the only reliable source.

**What this cannot do**

It cannot restore a banned account and cannot affect an account-level ban. Its
only job is to make the machine look like a machine that has never been seen.
